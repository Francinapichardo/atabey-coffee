# Atabey 🌿☕✨

> Urban nature, specialty coffee, and craft botanical cocktails in the heart of Mills 50, Orlando, FL.

Welcome to the official repository for **Atabey**—a sanctuary where specialty coffee, rare houseplants, and a peaceful zen patio coexist to disconnect from the modern noise.

## ✨ Features
- **Day & Night Mode:** Seamlessly switch between a bright daytime coffee shop vibe and a moody night bar atmosphere.
- **The Vibe & Chaos Center:** Interactive mood generators and random menu pickers for indecisive visitors.
- **Secret Lore Cards:** Tap-to-reveal secrets hidden inside our plant and coffee highlights.
- **Interactive Map & Community Gallery:** Embedded location finder and a live community feed preview.

## 🛠️ Built With
- HTML5
- CSS3 (Custom Properties & Flexbox/Grid)
- JavaScript (Vanilla)
